# argosy-docs

The labeled corpus for Argosy's retrieval eval. Its documents describe the
argosy system itself: real, multi-section prose so the eval exercises
heading chunking, hybrid ranking, and identifier queries the way real books
do. Labels live in `evals/retrieval.json`.

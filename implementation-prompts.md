# Argosy implementation prompt documents

`docs/prompts/00-*.md` … `10-*.md` are the chunked implementation plan for a flow-mode agent session, derived from `docs/specification.md` (normative) and `docs/reference-implementation.md` (informative). Implement in numeric order; each doc has a success-criteria checklist.

Locked decisions (doc 00 §3, user-confirmed 2026-08-26):
- Single crate `argosy` (lib + bin); default vector store = **sqlite-vec** at `<project-root>/.argosy/index.db`
- Default embedding = **fastembed** (ONNX, AllMiniLML6V2) behind `EmbeddingProvider` trait; gated `#[ignore]` smoke test only — CI/default `cargo test` must never need network
- One embedding unit per concept (chunking deferred per spec §15); precedence = local first, then imports in registration order
- Cargo features: `default = ["default-index", "mcp"]` — end state (REACHED)

Tooling locked 2026-08-27 (user request): **snafu** for errors (not thiserror), **yaml_serde** for YAML (not serde_yaml). Future chunks must use snafu context selectors with `OptionExt`/`ResultExt`.
